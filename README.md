# Практическая работа №2 — сайт кофейни

Учебный многостраничный проект на Flask. В приложении реализованы главная страница, меню и страница о кофейне, общий шаблон Jinja, отдельный CSS-файл и адаптивная верстка.

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
